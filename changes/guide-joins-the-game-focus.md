- With the game's gamepad interface, the guide window now joins the game's
  own window focus: the "Browse the guide" binding moves the game's cursor
  onto it, A presses what the cursor is on, B gives the focus back with the
  window still open, and the game's focus button cycles to it like any of
  its own windows. A fight takes it out of the cycle and gives it back the
  focus afterwards if it had it.
